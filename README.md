## 📝 Deskripsi Proyek
Proyek ini bertujuan untuk membangun model klasifikasi citra berbasis *Machine Learning* menggunakan algoritma **Multi-Layer Perceptron (MLP)**. Dataset yang digunakan adalah **Flowers Recognition** dari Kaggle yang terdiri dari 5 kategori/kelas citra bunga:
1. `Daisy`
2. `Dandelion`
3. `Rose`
4. `Sunflower`
5. `Tulip`

Proyek ini mencakup seluruh alur pengerjaan *computer vision* dasar, mulai dari ekstraksi fitur citra, preprocessing data, pembagian dataset (train-test split), pelatihan jaringan saraf tiruan (MLP), hingga evaluasi metrik dan visualisasi hasil prediksi.
